# Quote and measurement improvements — 22 October 2026

- Reusable quote/invoice templates now show customer-filled previews. Itemisation and agreed pricing still use the existing document engine.
- Quote PDFs use compression; satellite snapshots use JPEG, include outlines, and handle mixed mapped/sketched geometry separately. If imagery is unavailable the diagram remains explicitly labelled; it is not called aerial imagery.
- Successful sends update Quote Sent through the existing confirmed-send callback. Drafts and failed sends do not.
- 3D picked corners render at surface elevation without changing ground/surface measurement calculations. Property pin and Return to property controls are available.
- Extension 0.2.7 reuses CRM tabs on Open in TurnKey. Saved-quote handoffs reload the tab to fetch authoritative saved data. Save unrelated edits first.

## Validation and limits

Focused document, measurement and extension tests; assembled desktop/mobile browser checks; static build. Maps responses in automated browser checks are simulated. No real customer email or booking was sent. A 14.1 MB PNG fixture produced a 506 KB compressed PDF. The existing attachment ceiling remains enforced.

No database migration or backend credential changes are required for this release. Install extension 0.2.7 and refresh Earth/TurnKey.

## Still requires setup / separate implementation

Setmore calendar integration and autonomous email/booking assistant are not included. Setmore requires Pro and approved API access; account access and the user's preferred approval/automatic mode are pending. Availability, staff/service mapping and booking conflict recovery need verification before enabling autonomous bookings.

Email-open tracking is not implemented. Personal Gmail does not supply native read receipts; tracking pixels, if added, would be only an unreliable open signal, not proof of reading.
